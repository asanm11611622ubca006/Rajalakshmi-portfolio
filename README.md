# Rajalakshmi R — Personal Portfolio

A **100% frontend, dark-themed, motion-rich personal portfolio** built for **Rajalakshmi R** (BCA Graduate | AI/ML Trainee | Data Analytics Intern | Aspiring Process Associate).

Designed with obsidian-navy glassmorphism, an interactive neural-network `<canvas>` background across all sections, custom SVG project graphics, and distinct **GSAP + ScrollTrigger** animations for every section.

---

## ✨ Key Features

- **Dark Obsidian-Navy Theme:** Glassmorphic cards, glowing indigo/cyan/violet accents, and custom SVG illustrations.
- **Continuous Neural-Network Canvas:** Interactive particle & connection network running smoothly behind every section.
- **6 Distinct Section Animations (GSAP + ScrollTrigger + IntersectionObserver):**
  1. **Hero (`#hero`):** Kinetic text stagger + continuous scroll parallax on the orbital portrait stage.
  2. **About & Education (`#about`):** Opposing horizontal split slide-in + sequential education timeline pop.
  3. **Technical Skills (`#skills`):** 3D perspective card flip-in, category filter tabs, and animated skill meter bars.
  4. **Experience (`#experience`):** Kinetic skewed rise + cascading bullet points.
  5. **Projects (`#projects`):** Alternating tilt elastic pop-in + interactive project detail modal.
  6. **Certificates & Contact (`#certificates`, `#contact`):** 3D deck fan-out cascade with full-screen certificate lightbox + iris scale-up contact reveal with one-click copy and `mailto:` form.
- **Responsive Design:** Tailored for desktop/laptop, tablet, and mobile screens (unobstructed top portrait on mobile, 2×2 stats grid, and collapsible glass navbar).
- **Accessibility:** Respects `prefers-reduced-motion: reduce` and pauses background canvas work when the browser tab is hidden.

---

## 🛠️ Tech Stack (Frontend-Only)

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid/Flexbox, glassmorphism, keyframe orbits, responsive media queries
- **Vanilla JavaScript (ES6+)** — Canvas neural network, `IntersectionObserver`, modals, lightbox, clipboard copy
- **GSAP 3 & ScrollTrigger** (via CDN) — Smooth compositor-only animations
